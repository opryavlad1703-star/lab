# Лабораторна робота №10: Основи ООП в PHP (Менеджер завдань)

## Відповіді на контрольні питання

1. **Що таке інкапсуляція і як вона реалізована в класі Task?**
   * **Відповідь:** Інкапсуляція — це приховування внутрішнього стану об'єкта та захист від прямої модифікації. У класі `Task` властивості захищені через `private` та `readonly`, а доступ і зміни відбуваються через геттери та методи на кшталт `complete()`.

2. **Які переваги надає паттерн Repository?**
   * **Відповідь:** Він відокремлює логіку роботи зі сховищем даних від інтерфейсу користувача, що дозволяє легко змінити джерело даних без зміни інтерфейсу.

3. **Що таке Constructor Property Promotion у PHP 8?**
   * **Відповідь:** Синтаксичний цукор, що дозволяє оголошувати та ініціалізувати властивості класу прямо в аргументах конструктора.

4. **У чому різниця між методом toArray() та фабричним методом fromArray()?**
   * **Відповідь:** `toArray()` виконує серіалізацію об'єкта в масив для JSON, а `fromArray()` десеріалізує масив назад в екземпляр об'єкта `Task`.
