## Відповіді на контрольні питання (Лабораторна робота №9)

1. **Що таке «Шаблонні рядки» (Template Literals) у JavaScript і чим зручні зворотні лапки ( \` ) у порівнянні зі звичайними ( ' ) чи подвійними ( " ) при створенні HTML?**
   * **Відповідь:** Шаблонні рядки дозволяють створювати багаторядковий текст без конкатенації (`+`) та підтримують інтерполяцію змінних через синтаксис `${variable}`, що робить генерацію HTML набагато чистішою.

2. **Яка різниця між методом масиву `.forEach()` та `.map()`? Чому в нашому прикладі використано саме `.map()` в комбінації з `.join('')`?**
   * **Відповідь:** `.forEach()` просто виконує дію для кожного елемента і нічого не повертає, а `.map()` створює та повертає **новий масив** трансформованих елементів. `map()` перетворює масив об'єктів на масив HTML-рядків, а `.join('')` об'єднує цей масив у єдиний суцільний текстовий рядок для `innerHTML`.

3. **Чому ми створюємо масив товарів за допомогою ключового слова `const`, хіба його елементи не можна буде пізніше змінити / відсортувати?**
   * **Відповідь:** `const` забороняє лише повторне присвоєння самої змінної, але сам масив залишається мутабельним — ми можемо змінювати його вміст, додавати елементи чи сортувати.

4. **Для чого ми зберегли `id` в атрибуті кнопки як `data-id="${product.id}"`?**
   * **Відповідь:** Data-атрибути дозволяють зберігати кастомні дані безпосередньо в HTML-тегах, щоб у майбутньому при кліку на кнопку «Купити» легко зчитати ID товару.

5. **Навіщо скриптам додають атрибут `type="module"` під час підключення до сторінки?**
   * **Відповідь:** Він ізолює область видимості скрипта (захищає глобальний об'єкт `window`), автоматично вмикає суворий режим (`use strict`), робить скрипт `defer` (відкладеним) та дозволяє використовувати `import`/`export`.
