## Відповіді на контрольні питання (Лабораторна робота №12)

1. **Чому ми застосували до модального вікна position: fixed;, а не position: absolute;? Що сталося б, якби модалка була відкритою, а користувач прокрутив сторінку вниз?**
   * **Відповідь:** `position: fixed` фіксує елемент відносно вікна браузера, тому вікно залишається на місці під час скролу. З `position: absolute` вікно прокрутилося б разом зі сторінкою і зникло з екрана.

2. **Яка CSS властивість відповідає за те, щоб модальне вікно знаходилося “ближче” до глядача (перекривало інші елементи)?**
   * **Відповідь:** Властивість `z-index`.

3. **Який ключовий метод об’єкта classList (в JavaScript) дозволяє швидко додавати або забирати клас .hidden у відповідь на подію кліку без написання if...else?**
   * **Відповідь:** Метод `classList.toggle("hidden")`.

4. **Для чого ми написали перевірку if (event.target === cartOverlay) у функції закриття фону? Що сталося б без цієї перевірки?**
   * **Відповідь:** Щоб закриття відбувалося лише при кліку на темну підкладку, а не всередині білого вікна кошика (через спливання подій).

5. **Згадайте тег setTimeout. Якщо ми хочемо зробити модалку не тільки display: none, але й плавно прозорою (opacity), як JS і таймери можуть допомогти в організації анімації CSS?**
   * **Відповідь:** Таймери допомагають послідовно змінювати стилі: спочатку прибирати клас відображення (`display`), а через невелику затримку змінювати `opacity` для запуску плавного переходу (`transition`).
