## Відповіді на контрольні питання (Лабораторна робота №15)

1. **Навіщо при відправці форми обов’язково викликати метод event.preventDefault()?**
   * **Відповідь:** Щоб зупинити стандартну поведінку браузера — повне перезавантаження сторінки при відправці форми. Без цього весь стан JavaScript у пам'яті (зокрема заповнений масив кошика) буде повністю втрачено.

2. **У чому полягає перевага використання класу FormData у порівнянні з ручним пошуком окремих полів через document.querySelector()?**
   * **Відповідь:** `FormData` автоматично збирає всі значення полів форми за їхніми атрибутами `name`, позбавляючи від необхідності писати окремі `document.querySelector()` для кожного інпуту.

3. **Чому при створенні живого пошуку обробляється подія input, а не подія change?**
   * **Відповідь:** Подія `input` спрацьовує негайно при кожному введенні чи стиранні символу в реальному часі, тоді як подія `change` спрацьовує лише після того, як елемент втрачає фокус (blur).

4. **Як за допомогою методів trim() та toLowerCase() реалізувати стійкий регістронезалежний пошук за підрядком?**
   * **Відповідь:** За допомогою `trim()` ми видаляємо зайві пробіли з початку й кінця рядка користувача, а `toLowerCase()` переводить і запит, і назву товарів у нижній регістр, що дозволяє знайти збіги незалежно від того, якими літерами (великими чи маленькими) писав користувач.

5. **Чому для підрахунку підсумкової вартості товарів у кошику метод reduce() є більш безпечним та декларативним, ніж звичайний цикл for?**
   * **Відповідь:** `reduce()` є декларативним методом вищого порядку, який зосереджується на *тому*, що потрібно порахувати (акумулювати), а не на *як* це робити (ручне керування індексами й лічильниками в циклі `for`), що знижує ймовірність людських помилок і робить код чистішим.
