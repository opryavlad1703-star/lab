## Відповіді на контрольні питання (Лабораторна робота №17)

1. **Що таке СКБД (DBMS) та у чому полягає різниця між сервером MySQL і веб-інтерфейсом phpMyAdmin?**
* **СКБД (Система управління базами даних)** — це спеціалізоване програмне забезпечення для створення, збереження, пошуку, оновлення та адміністрування баз даних.
* **MySQL** — це сам сервер СКБД (ядро), який виконує фонову роботу: обробляє SQL-запити, фізично зберігає дані на диску, керує транзакціями та правами доступу.
* **phpMyAdmin** — це графічний веб-інтерфейс (клієнтська оболонка), написаний мовою PHP. Він не є базою даних, а лише надає зручну графічну панель у браузері для адміністрування сервера MySQL без необхідності вводити команди в терміналі.


2. **Для чого використовується атрибут Auto Increment (`A_I`), який призначається первинному полю `id`?**
* Атрибут **Auto Increment (`A_I`)** автоматически ґенерує унікальне послідовне числове значення ($1, 2, 3, \dots$) для кожного нового запису, який додається до таблиці.
* Це звільняє розробника від необхідності вручную обчислювати та передавати значення `id` під час виконання операції додавання (`INSERT`).


3. **Що таке PRIMARY KEY (Первинний ключ) і для чого він критично потрібен у кожній реляційній таблиці?**
* **PRIMARY KEY** — це поле (або комбінація полів), яке однозначно ідентифікує кожен рядок (запис) у реляційній таблиці.
* **Основні функції:**
1. **Унікальність:** Гарантує, що значення ключа є унікальним для кожного рядка та не може містити `NULL`.
2. **Швидкість:** Створює первинний індекс, що значно прискорює пошук, вибірку та оновлення даних.
3. **Зв'язки:** Слугує основою для зв'язування таблиць за допомогою зовнішніх ключів (Foreign Keys).




4. **Назвіть щонайменше 2 текстові типи даних у MySQL (`VARCHAR`, `TEXT`) та поясніть різницю між ними.**
* **`VARCHAR(N)`**:
* Рядок змінної довжини з явно вказаним максимальним лімітом $N$ (наприклад, `VARCHAR(255)`).
* Займає в пам'яті стільки байт, скільки реально містить символів + $1$–$2$ байти для службової інформації про довжину.
* Оптимальний для коротких текстів (логіни, email, заголовки) та повноцінно підтримує індексацію.


* **`TEXT`**:
* Призначений для збереження великих обсягів тексту (до $65\,535$ символів / $64$ КБ) без вказання максимальної довжини під час створення поля.
* Зберігається окремо від основного рядка таблиці, а його індексація потребує вказування довжини префікса.




5. **Чому для збереження паролів виділено стовпець `VARCHAR(255)`, а не поле меншої фіксованої довжини?**
* Паролі ніколи не зберігаються у відкритому вигляді — вони хешуються за допомогою криптографічних алгоритмів (наприклад, `password_hash()` у PHP, що використовує **Bcrypt** або **Argon2**).
* Підсумковий рядок хешу містить сам хеш, сіль (salt), налаштування алгоритму та метадані, тому має довжину від $60$ до $100+$ символів.
* Розмір `VARCHAR(255)` забезпечує запас пам'яті для безпечного зберігання хешів навіть у разі переходу на нові, більш стійкі криптографічні алгоритми без зміни структури БД.


6. **Що таке інтерфейс PDO (PHP Data Objects) у PHP та які суттєві переваги він надає порівняно із застарілим набором функцій `mysql_*`?**
* **PDO** — це універсальний об'єктно-орієнтований шар абстрації у PHP для безпечної роботи з різними системами керування базами даних.
* **Переваги над `mysql_*`:**
1. **Безпека:** Вбудована підтримка підготовлених виразів (Prepared Statements), що гарантує захист від SQL-ін'єкцій.
2. **Універсальність:** Дозволяє легко змінити СУБД (наприклад, з MySQL на PostgreSQL чи SQLite), змінивши лише рядок підключення, без переписування самих запитів.
3. **Обробка помилок:** Використовує механізм винятків (`PDOException`).
4. Функції `mysql_*` повністю вилучені з сучасних версій PHP (починаючи з PHP 7.0).




7. **Що таке рядок DSN (Data Source Name) та які обов'язкові компоненти входять до його складу під час з'єднання з MySQL?**
* **DSN (Data Source Name)** — це рядок конфігурації, який містить інформацію про джерело даних, необхідну драйверу PDO для встановлення з'єднання з сервером.
* **Обов'язкові компоненти для MySQL:**
* `mysql:` — назва драйвера СУБД.
* `host=` — адреса сервера (наприклад, `127.0.0.1` або `localhost`).
* `dbname=` — назва бази даних (наприклад, `task_manager`).
* `charset=` — кодування символів з'єднання (наприклад, `utf8mb4`).
* *(Опціонально)* `port=` — мережевий порт (за замовчуванням `3306`).




8. **Чому операцію встановлення з'єднання з базою даних через PDO необхідно огортати в блок `try...catch (PDOException)`?**
* У разі виникнення помилки підключення (невірно вказаний пароль, вимкнений сервер MySQL, відсутня БД) PDO генерує виняток `PDOException`.
* Якщо виняток не перехопити через `try...catch`, скрипт зупиниться з критичною помилкою (Fatal Error) і може вивести на екран детальний відлагоджувальний стек (stack trace), який містить конфіденційні дані (паролі, логін, внутрішні шляхи на сервері).
* Блок `try...catch` дозволяє безпечно перехопити помилку, обробити її, вивести зрозуміле для користувача повідомлення та приховати системні секрети.
